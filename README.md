# Ryankey Studios — Next.js Web Application

Ryankey Studios is a creative photography and videography studio based in Nairobi, Kenya. This application is built with Next.js (App Router), React, Tailwind CSS, Framer Motion, and shadcn/ui.

## Technologies Used

- **Framework:** Next.js 14 (App Router)
- **UI & Components:** React 18, Radix UI (shadcn/ui), Tailwind CSS, Framer Motion
- **Smooth Scrolling:** Lenis
- **Icons:** Lucide React
- **State & Data:** TanStack Query

## Getting Started

### 1. Install dependencies
```sh
npm install
```

### 2. Run the development server
```sh
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Production Build
```sh
npm run build
npm run start
```

## Routes & Pages

- `/` — Homepage (Hero, Brand Marquee, About preview, Services preview, Portfolio preview, Testimonials, CTA)
- `/about` — About Ryankey Studios & Studio Story
- `/services` — Photography & Videography Services
- `/portfolio` — Featured Works & Social Hub
- `/gallery` — 3D Interactive Gallery Showcase
- `/pricing` — Rate Card & Packages
- `/contact` — Booking Form, Direct WhatsApp, and Location Map
